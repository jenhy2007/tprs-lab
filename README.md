🇮🇹 TPRS 意大利语实验室 · Italian TPRS Lab

一个专为零压力、高可理解性输入（Comprehensible Input）设计的个人意大利语学习实验室。不背枯燥语法表、不考默写，通过超短“大伞”句型与趣味视听内容，每天轻松积累 1+ 分钟的真实语感。

📂 文件结构 · Project Files

index.html — 实验室主页入口，集中导航所有学习卡片。

tprs-live-card.html — 核心大伞练习卡：提供 2–4 词超短起手句、单槽替换（Single-Slot Substitution）练习与实时对话记录。

fun-italian-card.html — 趣味意大利卡片：收藏双语搞笑歌曲与日常短视频链接（支持本地随时新增链接），附带高频刷视频反应词块一键语音点读与 Markdown 导出功能。

✨ 设计理念 · Core Principles

大伞框架（Umbrella Framework）：用极简的高频核心句型作为“大伞”，每次只替换一个词槽，避免认知超载。

快乐优先（Joyful Input）：把刷到的双语歌词与趣味短视频直接沉淀为词块，用旋律与情绪带动自然习得。

随手备份（NotebookLM Sync）：支持一键复制 Markdown 学习记录与收藏清单，方便同步至 NotebookLM 长期保存。
